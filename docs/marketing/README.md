# Marketing source

This directory keeps the Bilibili production source, Zhihu article text, and
Xiaohongshu export notes. The rendered video, screenshots, image
exports, Word file, and working browser profile stay local and are excluded by
the root `.gitignore`.

- `bilibili/zotero-chatgpt-bilibili-kit/remotion/`: current 48-second video source.
  Its README lists the locally required demo footage and build steps. The old
  65-second prompt, manifest, and shot list have been retired.
- `bilibili/zotero-chatgpt-bilibili-kit/release/BILIBILI_COPY.md`: draft post copy.
- `zhihu/zhihu-article.md`: editable article source.
- `xhs/README.txt`: card sequence and export dimensions; the card images remain local.

Marketing claims are drafts. The product contract and current verification
status live in `docs/zotero-chatgpt-user-flow.md` and `docs/progress.md`.
